LEFT OR RIGHT - iPhone PWA

가장 쉬운 사용 방법

1. 이 폴더의 파일들을 GitHub 저장소에 그대로 업로드합니다.
2. GitHub Pages를 켭니다.
3. 생성된 주소를 iPhone Safari로 엽니다.
4. Safari 공유 버튼 → '홈 화면에 추가'를 누릅니다.
5. 이후 홈 화면 아이콘으로 실행할 수 있습니다.
6. 한 번 실행한 뒤에는 오프라인에서도 실행됩니다.

기본 게임 설정
- 최소 대기시간: 1초
- 최대 대기시간: 5초
- 매 회차마다 범위 내에서 랜덤 대기
- 화살표는 약 0.65초 표시
